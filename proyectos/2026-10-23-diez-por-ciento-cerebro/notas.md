# El diez por ciento del cerebro

Pedido el 2026-10-23 para @quetaninteligente. Es el primero de esa lista, así que el cierre es el de enviárselo a un amigo, no el de la app.

Se cuenta el mito del diez por ciento con el matiz de verdad: no hay un almacén apagado, no hace falta encenderlo todo en el mismo segundo, y un golpe pequeño en una zona sí se nota. Las cifras (una parte de cada cincuenta, una caloría de cada cinco) salen de Raichle y Gusnard, 2002.

El primer cerebro, hecho de puntos, no se leía. Se rehízo de perfil, con volumen, surcos y el cerebelo rayado, que es la silueta que se reconoce. El cuerpo de las calorías va tumbado de frente a la cámara para que las piezas no se disparen de tamaño.
